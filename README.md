#  AI Study Assistant

A beginner-friendly Generative AI web application built using Python, Streamlit, and Groq API.

This application allows users to interact with an LLM (Large Language Model) to perform different educational tasks.

---

# 🚀 Features

The app includes 3 AI-powered features:

1. Explain a Concept
2. Summarize Text
3. Generate Quiz Questions

---

# ✨ Bonus Features Implemented

* Chat History
* Web Interface using Streamlit
* Loading Animation
* Markdown Rendering
* Empty Input Handling

---

# 🛠️ Technologies Used

* Python
* Streamlit
* Groq API
* OpenAI GPT-OSS-120B model
* python-dotenv

# ⚙️ Installation & Setup

## 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

---

## 2. Open Project Folder

```bash
cd YOUR_PROJECT_FOLDER
```

---

## 3. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 4. Create `.env` File

Add your Groq API key:

```text
GROQ_API_KEY=YOUR_API_KEY_HERE
```

---

## 5. Run the Application

```bash
streamlit run app.py
```
